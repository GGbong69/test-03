#  동전 얼굴 — 도트 격자. 글 하나가 도트 하나다.
#
#  == <id>  <이름>      새 장이 시작된다
#  = <글> <색>          팔레트 한 줄
#  그 뒤 서른여섯 줄    그림. 마침표는 비운다(동전 바탕이 비친다)
#
#  ── 한 벌의 말투 ─────────────────────────────────────────
#  쉰일곱 장을 한 판에 놓았을 때 **장마다 솜씨가 아니라 말투가 달랐다** —
#  외곽선이 있다 없다, 빛이 왼쪽에서 왔다 오른쪽에서 왔다, 바탕이 흰색·검정·
#  분홍·회색. 한 장씩은 괜찮은데 한 판으로는 남의 그림 쉰일곱 장이었다.
#  그래서 규칙을 넷으로 못박았다(scripts/tools/coin_paint.py 가 지킨다).
#    ① 팔레트가 하나다      coin_paint.PAL 의 램프 열넷 × 네 단
#    ② 빛이 하나다          왼쪽 위
#    ③ 테두리선이 없다      물건끼리는 선이 아니라 밝기 차로 가른다
#    ④ 바탕이 하나의 꼴이다  가운데가 밝고 가장자리가 한 단 가라앉는다
#
#  ③ 은 사용자가 정했다(2026-09-16). 외곽선·어두운 바탕·조각선을 넣은 시범
#  피자보다 **선 없이 밝고 큰 덩어리였던 첫 피자**가 낫다고 했다. 그 피자(c04)
#  는 그대로 두고 나머지 쉰여섯 장을 그 느낌 쪽으로 다시 그렸다.
#
#  새 장을 그릴 때는 붓으로 밑그림을 지은 뒤 이 격자를 손으로 다듬는다.
#  고친 장은 scripts/tools/coin_try.py 로 크게 보고(팔레트 밖 색도 거기서
#  잡힌다), scripts/tools/coin_sheet.py 로 한 판에 놓고 튀는지 본다.
#
#  원형 알파가 네 귀퉁이를 깎는다 — 뜻은 가운데 28x28 안에 둔다.
#  레퍼런스는 구도와 색의 분위기만 봤다. 받아 둔 원본은 저장소에 없다.
