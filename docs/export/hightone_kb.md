# HIGHTONE — 게임 전체 정보 (LLM 학습용 자료)

> 이 문서는 게임 기획서를 쓰기 위한 **원본 자료**다. 게임 빌드에서 자동으로 뽑았다.
> `scripts/tools/export_kb.py` 가 `data/*.csv` 16장과 `scripts/*.gd` 3장을 읽어 만든다.
> 사람이 손으로 적은 수치는 한 칸도 없다. 짝이 되는 기계용 파일은 `hightone_kb.json` 이다.

**읽는 규약**

- 빈 칸(`—`)은 **미정**이다. 0 과 다르다.
- `사용` 열이 `✗` 인 행은 데이터만 실려 있고 게임에 안 뜬다.
- `비고` 열은 그 값을 그렇게 정한 **이유**다. 밸런스 판단의 근거로 쓴다.
- 확정도는 세 단계다 — **확정** / **가안** / **제안**.

**LLM 에 먹이는 법**

1. 기획서 초안을 쓰게 하려면 이 `.md` 를 통째로 올린다. 문장과 표가 같이 있어 맥락이 안 끊긴다.
2. 수치 계산·밸런스 시뮬레이션·표 재가공을 시키려면 `hightone_kb.json` 을 올린다. 같은 내용이 타입 있는 값으로 들어 있다.
3. 둘 다 올리는 것이 가장 좋다. 그리고 이렇게 못 박아 준다 — **"미정 칸을 임의로 채우지 말고 미정으로 남겨라. 없는 수치를 지어내지 마라."**
4. 이 문서에 없는 것 — 상업 계획 · 가격 · 출시 일정 · 아트 리소스 · 스토리 대사. 아직 정하지 않았다.

## 2. 핵심 루프

- 런 = 앤티 8개 × 판 3개 = 판 24개. 진행 상태는 정수 round_no(1..24) 하나뿐이다.
- 앤티 = (n-1)/3 + 1 · 판 종류 = (n-1) % 3
- 판 하나 = 다트 6발(기본). 목표 점수를 넘기면 즉시 종료, 못 넘기면 런이 끝난다.
- 판을 넘길 때마다 상점이 열린다. 보스 판 앞에는 제약 선택 화면이 선다.

**화면 순서**

```
  제목
  ↓
  새 런(팩·리그 선택)
  ↓
  판 선택(던지기/건너뛰기)
  ↓
  [보스 앞] 제약 선택
  ↓
  조준 → 착탄 → 정산 반복
  ↓
  판 정산(골드)
  ↓
  상점
  ↓
  다음 판
```

**한 판 안에서**

```
  다트 고르기(PICK) → 조준 1축(AIM_V) → 조준 2축(AIM_H) → 확인(CONFIRM)
        → 비행(FLY) → 정산(RESOLVE) → [목표 미달이고 다트 남음] 다시 PICK
                                     → [목표 달성 또는 다트 소진] 판 정산(CLEAR)
```

- 목표를 **넘긴 순간** 라운드가 끝난다. 남은 다트는 골드로 환산된다.
- 목표를 못 넘기면 런이 끝난다. 단, `save` 종류 스티커가 있으면 1회 무를 수 있다.

## 3. 점수 계산

### 3-1. 공식

```
  한 발의 점수 = 칩(chip) × 배수(mult)
  라운드 총점 = Σ 한 발의 점수
  클리어 조건 = 총점 ≥ 목표
```

- **칩**: 꽂힌 칸의 값(1~20 · 불 25 · 이너 불 50 · 보드 아웃 0).
- **배수**: 꽂힌 영역의 배수(싱글 1 · 더블 2 · 트리플 3 · 불 1 · 빗나감은 큐가 1을 넣는다).
- 계산 방식은 스타트팩이 쥔다. `std` = 칩 × 배수 · `bal` = ((칩+배수)/2)². `bal` 은 한쪽만 쌓는 빌드를 죽이고 양쪽을 고르게 올린 빌드를 가장 크게 만든다.

### 3-2. 한 발의 정산 큐

정산은 큐를 한 걸음씩 판다. 걸음마다 소리가 반음 오른다.

1. 칩(칸 값)
2. 배수(영역)
3. [관통 다트] 양옆 칸 평균의 절반
4. 발동한 스티커를 랙 순서대로
5. 합산 — 칩 × 배수를 총점에 더한다

- 스티커는 랙에 꽂힌 순서대로 정산된다. ×배수가 뒤에 오면 앞의 +배수를 전부 곱하므로 순서가 곧 빌드다.
- 칸을 죽이는 축은 번호 → 색 → 홀짝 순으로 좁아진다. 링을 죽이는 축은 값은 두고 배수만 1로 내린다.
- 다트 보정(fix1 · mult · pierce)이 먼저, 영역 강화 트랙이 그 뒤다. 무거운 다트가 트랙 투자를 통째로 먹지 않게 한 순서다.
- "…맞힌 뒤" 조건은 완성한 그 발이 아니라 다음 발부터 선다.
- 정산 걸음은 5.0걸음까지 같은 박자, 그 뒤로 걸음마다 0.055씩 짧아져 0.3에서 멎는다.
- 정산 한 걸음마다 소리가 반음씩 오른다(392Hz × 2^(n/12)). 게임 이름이 여기서 왔다.

### 3-3. 효과 종류 (`kind`)

## 5. 조준 방식

- 조준 방식은 **든 스티커**가 쥔다(a*** 스티커 7장). 팩이 아니라 스티커라 사고 팔고 봉인되는 규칙 아래 놓인다.
- 게이지가 왕복하고 누른 순간 그 축이 잠긴다. 세로 먼저, 가로 다음.
- 게이지 속도 0.7. 게임 중 [ ] 키로 조절된다. 제약 '역풍'과 설비 '침착'이 같은 축을 민다.

| mode | 이름 | 잠금 횟수 | 하는 일 | 화면 안내 |
|---|---|---|---|---|
| std | 기본 | 2 | 게이지가 왕복하고 누른 순간 그 축이 잠긴다 | 다트판을 눌러 높이 결정 → 다트판을 눌러 좌우 결정 |
| ring | 원 | 2 | 원의 크기와 각도로 조준합니다 | 다트판을 눌러 원 크기 결정 → 다트판을 눌러 각도 결정 |

판의 **기하**를 영구히 바꾼다. 상점에서 사면 런이 끝날 때까지 남는다.

- **기본 팩** — 기준선. 튜닝 표의 값을 그대로 쓴다 — 이 팩의 효과 줄이 곧 게임의 기본값이다
- **여벌 팩** — 다트 하나를 더 주되 잔탄이 값을 잃는다. 여벌이 있으니 아껴 쓸 이유가 없다는 것이 이 팩의 말이다 — 점수는 오르고 "일찍 끝내 골드를 번다" 는 길이 닫힌다
- **넓은 랙** — 스티커 한 칸을 다트 한 발과 바꾼다. 칸이 여섯이면 칸 폭이 62 → 53 이 된다
- **선금 팩** — 선금을 받고 소비 칸 하나를 내준다. 첫 상점에서 희귀(11~14)에 손이 닿는 대신 판을 고칠 여지가 준다
- **일당 팩** — 이자를 끄고 잔탄 골드를 두 배로. 모으는 대신 남기는 판이 된다
- **미정** — 히든 자리. 조준·계산 변형은 아직 안 정했다 — aim/score 를 std 가 아닌 이름으로 바꾸고 그 이름을 AIM_MODES/SCORE_MODES 에 등록하면 산다. 지금은 기본과 똑같이 돈다

- 이자 — 보유 5골드당 1, 상한 5

- 스티커 판매
- 건너뛴 판의 딱지

**골드가 나가는 곳**

- 매대 구매(스티커 · 개조 · 다트 · 소비)
- 유료 새로고침
- 설비 구매
- 리그 유지비 — 판마다 3골드 (검정 리그)

- 판매가 = 구매가 ÷ 2(내림), 최소 2. 4/7/11/14 → 2/3/5/7 이다.
- 무료 1회, 이후 2골드에서 시작해 1씩 오른다.
- 판매 스프레드(구매가 − 판매가) = 2 / 4 / 6 / 7. 이것이 "한 정산만 빌려 쓰고 되팔기" 의 손익선이다.

**상점 규칙**

- 판 N 을 클리어한 뒤 N+1 을 위해 열린다. 마지막 판 뒤에는 안 연다.
- 매대 자리는 정확히 4개다 (스티커 2 · 개조 1 · 다트 1).
- 스티커는 등급 가중치로 뽑는다. 이미 가진 것과 아직 안 풀린 것은 애초에 후보에서 빠진다.
- 판이 더는 못 받는 개조(기하 순서 위반 · 판값 상한 초과)와 이미 산 개조는 후보에서 빠진다. 무효 구매가 존재할 수 없다.
- 설비는 매대가 아니라 왼쪽 벽에 걸린다. 앤티당 하나, 새로고침으로 안 씻긴다.
- 매물은 딜러가 펠트 위로 던져 굴린다. 새로고침하면 쓸어 담고 다시 던진다. 구매는 물건을 계산대로 밀거나 두 번 누른다.

## 19. 어휘 사전

### 19-1. 발동 조건 (`cond`) — 35가지

| cond | 짧은 말 | 카드 문장 |
|---|---|---|
| always | 언제나 | 모든 다트 |
| triple | 트리플 | 트리플 명중 시 |
| double | 더블 | 더블 명중 시 |
| band | 띠 | 트리플·더블 어디든 |
| bull | 불 | 불 명중 시 |
| odd | 홀수 | 홀수 섹터 명중 시 |
| even | 짝수 | 짝수 섹터 명중 시 |
| left | 왼쪽 | 왼쪽 절반 명중 시 |
| right | 오른쪽 | 오른쪽 절반 명중 시 |
| big | 15 이상 | 15 이상 섹터 명중 시 |
| mid | 6~14 | 6~14 섹터 명중 시 |
| small | 5 이하 | 5 이하 섹터 명중 시 |
| same | 같은 칸 | 직전과 같은 섹터면 |
| diff | 다른 칸 | 직전과 다른 섹터면 |
| first | 첫 발 | 라운드 첫 다트에 |
| last | 막 발 | 라운드 마지막 다트에 |
| streak | 연속 | 연속 명중 1회마다 |
| warm | 트리플 뒤 | 이번 라운드에 트리플을 맞힌 뒤 |
| miss | 빗나감 | 빗나가면 |
| missp | 연속 빗나감 | 직전 투척이 빗나갔다면 |
| risk | 더블·트리플·불 | 더블·트리플·불 명중 시 |
| risk1 | 첫 고난도 | 라운드 첫 더블·트리플·불 명중 시 |
| few | 다트 3 이하 | 이번 라운드 다트가 3개 이하면 |
| sixth | 여섯째 | 매 6번째 투척에 |
| pair | 같은 수 2 | 같은 숫자 2회를 맞힌 뒤 |
| trip | 같은 수 3 | 같은 숫자 3회를 맞힌 뒤 |
| quad | 같은 수 4 | 같은 숫자 4회를 맞힌 뒤 |
| pair2 | 두 쌍 | 다른 두 숫자를 각 2회 맞힌 뒤 |
| spread | 세 곳 | 다른 숫자 세 곳을 맞힌 뒤 |
| zone3 | 한 영역 3 | 같은 영역 종류 3회를 맞힌 뒤 |
| zones2 | 두 영역 | 다른 영역 2종을 맞힌 뒤 |
| zones4 | 네 영역 | 네 영역을 모두 맞힌 뒤 |
| rezone | 다시 그 영역 | 이미 명중한 영역을 다시 맞히면 |
| `sec:20,5` | 20·5번 | 20·5번 명중 시 |
| `col:1` | 먹 | 먹 칸 명중 시 |

- `sec:N,M` — 지정한 번호 칸에 명중. `col:N` — 지정한 색 칸에 명중.
- 빗나가면 명중 조건은 전부 죽는다. 예외는 `miss` 와 `missp` 둘뿐이다.
- "…맞힌 뒤" 패턴 조건은 완성한 그 발이 아니라 **다음 발부터** 선다.

**포함 관계** (`COND_SUB` — A 로 뜨는 다트는 B 로도 뜬다)

| A | 담는 것 B |
|---|---|
| always | triple, double, band, bull, odd, even, left, right, big, mid, small, same, diff, first, last, streak, warm, risk, risk1, few, sixth, pair, trip, quad, pair2, spread, zone3, zones2, zones4, rezone, sec |
| risk | triple, double, band, bull, risk1 |
| band | triple, double |
| same | streak |
| streak | same |
| diff | first |
| pair | trip, quad, pair2 |
| trip | quad |
| zones2 | zones4 |

**완전분할** (`COND_PART` — 같은 효과로 한 분할을 다 덮으면 무조건 카드가 된다)

- left + right
- odd + even
- mid + big + small
