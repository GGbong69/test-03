# 건너뛰기 보상 — 기획자 표 (2026-09-15)

> **표는 `data/tags.csv` 다.** 이 문서는 읽으라고 만든 거울이고, 고치는 곳은 그 표다.
> 값·무게·라운드·문구는 표 하나로 끝난다. **새 갈래**를 만들려면 `data.gd` 의
> `TAG_KINDS` 와 `game.gd` 의 `_take_tag_once` 를 같이 낸다.

## 1. 언제 고르는가

한 라운드는 판 셋이다 — 작은 판 · 큰 판 · 보스 판. 앞의 둘만 건너뛸 수 있다.
한 런이 8라운드이므로 **건너뛸 수 있는 자리는 열여섯**이다.

보상은 라운드가 열릴 때 그 라운드 몫을 한꺼번에 굴린다 — 작은 판을 고르기
전에 큰 판 보상이 이미 보인다. 건너뛰면 그 판의 점수도 골드(작은 3 · 큰 4)도 없다.

## 3. 정해 둔 규칙

**발품** — 이 뱃지를 준 건너뛰기까지 센다(그래서 최소 5). **지금까지** 건너뛴
판을 세지 앞으로를 세지 않는다. 늦게 받을수록 크고, 상한은 16판 × 5 = 80이다.

**쌍둥이** — 다음에 받는 뱃지 하나가 두 번 걸린다. 쌍둥이를 또 받으면 쌓인다
(둘이면 세 번). 쓰는 순간 비운다. 라운드를 넘어가도 남는다.

**주력 트랙** — `track_hits` 를 읽는다. 동점이면 그중 무작위, 한 발도 안
맞혔으면 무작위 트랙. 라운드 4부터인 것은 그 전에는 표본이 적어 사실상
무작위이기 때문이다.

**현상금** — 이번 라운드 보스를 넘기면 정산에 「현상금」 줄로 붙는다.
**이자를 센 뒤**라 제 몫에 이자가 안 붙는다. 못 넘기면 런이 끝나므로 0이다.
마지막 판(라운드 8 보스)은 정산 화면을 안 거치므로 완주 갈래에서 따로 치른다.

**빈손으로 끝나는 길** — 사탕·사진·동전 셋은 칸이 꽉 차 있으면 아무것도 안
온다. 그때는 **화면이 그렇게 말한다**(「사탕 칸이 꽉 찼다」 · 「동전 슬롯이
꽉 찼다」 · 「남은 동전이 없다」). 전에는 잠자코 있었다.

## 4. 표에서 **빠진** 것

- **여벌 다트**(다음 판 다트 +1) — 기획에서 빠졌다. 이제 던지는 판을
  건드리는 보상이 하나도 없다.
- **여유로운 선택**(제약 선택지 +1) — 기획에서 빠졌다. 보스 판을 건드리는
  보상은 현상금뿐이다.
- **보유 골드 2배(상한 20)** — 사진 「오리 금고」(`v_cash`)가 글자 그대로
  같은 일을 한다. 뱃지로 또 두면 「한 컷」이 제 열화판을 뽑아 줄 수 있다.

셋 다 갈래(`dart` · `picks`)와 꺼내는 자리는 코드에 남겨 두었다 —
되살리는 것이 표에 한 줄이다.

## 5. 갈래마다 코드가 하는 일

| 갈래 | 하는 일 |
|---|---|
| `gold` | 골드 +v. 챌린지 「빈손」의 `tag_mul` 을 탄다 |
| `track` | 무작위 트랙 하나 +v단. 목록은 `areas.csv` 가 낸다 |
| `candy` | 무작위 사탕 v개 (사탕은 전부 트랙 강화 한 장) |
| `photo` | 무작위 사진 v장. 사탕과 **같은 칸**을 쓴다 |
| `item` | `rarity` 등급의 아직 없는 동전 v장 |
| `reroll` | 다음 상점 무료 리롤 +v회 |
| `shop` | 다음 상점 매물 +v칸 |
| `free` | 다음 상점 물건 v개가 공짜 |
| `boss_gold` | 이번 라운드 보스를 넘기면 골드 +v |
| `skip_gold` | 지금까지 건너뛴 판마다 골드 +v |
| `track_top` | 가장 많이 맞힌 트랙 +v단 |
| `copy` | 다음 뱃지가 한 번 더 걸린다 |
| `dart` · `picks` | **지금 표에 쓰는 줄이 없다** |
