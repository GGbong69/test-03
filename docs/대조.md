## 효과 칸 수치 — 17건 (2026-09-13)

전에는 기획서 표의 **이름 · 가격 · 희귀도**만 맞췄고 **효과 칸의 수**는 손으로
고른 열몇 장만 봤다. 그 사이로 열일곱 장이 새어 나갔다. 다섯 장은 검증기의
「상위호환」 검사를 통과시키려고 **내가 일부러 덮은 값**이었고, 그 자리마다
`_note` 에 「기획서 값은 …」이라 적어 두었었다. 값은 기획서가 쥔다.

| 동전 | 표가 들던 값 | 기획서 |
|---|---|---|
| 발라트로의 조커 | 배수 +4 | **+2** |
| 닌자 | 무거운 다트 1개당 배수 +2 | **+1** |
| 위대한 피자 | 배수 +32 · 판마다 −4 | **+8 · 판마다 −1** |
| 금요일 | 배수 +0~23 | **+0~13** |
| 천동설 | 점수 +20 · 배수 +4 | **배수 +2** |
| 가장자리 | 배수 +6 | **+4** |
| 스파르타 | 배수 +20 | **+10** |
| HOPE | 배수 +15 | **+18** |
| 좌익수 | 배수 +5 | **+2** |
| 우익수 | 배수 +5 | **+3** |
| PART II | 배수 +8 | **+2** |
| 베르툼누스 | 보유 1개당 배수 +3 | **+2** |
| 2300 | 점수 +30 | **+23** |

**기획서 값을 넣으면 상위호환이 네 쌍 생긴다** — 발라트로의 조커가 좌익수와

이것은 기획서 값의 사실이므로 검사를 **오류에서 경고로 내렸다.** 값을 맞추는
것은 저자의 일이고 검사는 그 자리를 가리키는 일만 한다.
