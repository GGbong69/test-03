# 크레딧

빌려 온 것과 그 조건. **여기 적힌 것을 화면에서 지우면 배포 조건을 깬다.**
화면의 자리는 타이틀 맨 아랫줄이고, 글자는 `scripts/game.gd` 의 `CREDITS` 다.

## 효과음 — JDSherbert, Ultimate UI SFX Pack (FREE)

- 받은 곳 https://jdsherbert.itch.io/
- 조건
  - 상업적·비상업적 사용 모두 허락한다
  - **만든이를 적어야 한다** — 이것이 화면의 저 한 줄이다
  - 원본을 고치거나(modify·edit) 다시 배포하지 말 것

마지막 조건 때문에 **파일 자체는 한 바이트도 안 고쳤다.** 앞무음을 자르고
싶은 자리가 있었지만(Swipe 둘이 117ms·68ms 를 달고 있었다) 파일을 자르는
대신 고닷 임포터의 `edit/trim` 을 켰다 — 원본은 그대로 두고 가져올 때만
잘린다. 같은 이유로 모노·44.1kHz 변환도 안 했다. 팩이 이미 그 형식으로
`Mono/wav (SD)` 를 함께 주므로 그쪽을 그대로 가져왔다.

### 어느 소리가 어디에 앉았는가

파일 하나가 여러 자리에 앉는다 — `sfx/<이름>.wav` 규칙이라 이름마다 복사본이
하나씩 필요하다. 원본 11개가 21개 자리로 갔다.

| 팩의 소리 | 앉은 자리 |
|---|---|
| Select - 1 | `menu_pick` · `run_start` |
| Select - 2 | `league_pick` |
| Cursor - 1 | `hand_drop` |
| Cursor - 2 | `menu_pick2` · `shop_select` · `rack_select` · `rack_move` |
| Cursor - 4 | `shop_deselect` · `rack_deselect` · `hand_take` · `drop_skip` |
| Popup Open - 1 | `shop_open` · `newrun_open` |
| Popup Close - 1 | `menu_back` · `back` |
| Cancel - 1 | `deny` |
| Swipe - 1 | `page` |
| Swipe - 2 | `pack_flip` · `reroll` |
| Error - 1 | `run_lose` |

안 쓴 것 셋 — `Cancel - 2`(0.59초라 UI 에 과하다) · `Cursor - 3`(알맹이가
20kHz 라 사실상 안 들린다) · `Cursor - 5`(15.8kHz, 같은 이유로 피했다).
