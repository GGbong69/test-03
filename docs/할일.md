# 할 일

## 「랙」이라는 말을 없앤다

기획서에서는 걷어냈다. 게임 코드에는 아직 남아 있다.

| | |
|---|---|
| **무엇인가** | 스티커를 꽂는 자리. 기본 5칸이고, 왼쪽부터 차례로 정산한다 |
| **왜 없애나** | 기획서를 읽는 사람에게 뜻이 안 통한다. 「스티커 칸」이면 설명이 필요 없다 |
| **없애는 것은 말뿐이다** | 5칸이라는 구조와 왼쪽부터 도는 순서는 그대로다 |

**남아 있는 자리**

| 파일 | 횟수 |
|---|---|
| `scripts/game.gd` | 128 |
| `scripts/data.gd` | 5 |

**바꿀 말**

| 지금 | 바꿀 말 |
|---|---|
| 랙 | 스티커 칸 |
| 스티커 랙 | 스티커 칸 |
| 빈 랙 | 빈 스티커 칸 |

**주의**

- `트랙`(영역 강화 트랙)에 「랙」이 들어 있다. 통째로 바꾸면 `트스티커 칸` 이 된다. 긴 말부터 잡거나 단어 경계를 봐야 한다
- 아이템 이름 두 장이 이 말을 쓴다 — `랙 집합체`(j002), `빈 랙 형판`. 이름을 바꾸면 `data/items.csv` 와 `docs/자료표.md`, `docs/export/hightone_kb.json` 이 같이 움직인다
- 저장 파일에 이 말이 키로 들어가 있으면 이전 저장이 깨진다. `scripts/save.gd` 를 먼저 확인한다

**기획서 쪽은 이미 처리했다.** `scripts/tools/make_deck.py` 의 `TERMS` 가 옮긴다. 코드를 고치고 나면 그 줄을 지워도 된다.

## 저장소와 기획서의 계층이 다르다

기획서는 **런 > 라운드 8 > 판 3** 이다. 코드는 **앤티 > 판 > 라운드** 로 적는다.
지금은 `make_deck.py` 의 `KB_RENAME` 이 읽을 때 옮긴다. 코드를 맞추려면
`data/antes.csv` 의 `ante` 열과 `scripts/data.gd` · `scripts/game.gd` 의
`round_no` 를 같이 손봐야 한다.
